**PROJECT DESCRIPTION**

This software project is a functional unit converter built using HTML, CSS and JavaScript. It allows users to convert between different units of length.

The development of this project followed a professional Git CLI workflow:
    **Initialization:** Local repository setup with git init.
    **Branching Strategy:** Used a feature-update branch to implement new features without affecting the stable main code.
    **Remote Deployment:** Hosted on GitHub with a live version available via GitHub Pages.
